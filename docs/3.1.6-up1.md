# 3.1.6-up1

Base: upstream tag `3.1.6` (`39a8a77`), not the old local checkout at `2.1.4`.

- Upgrade PHP 8.2.7 to 8.2.35, Alpine 3.18 to 3.24.
- Preserve local customizations: APK certbot instead of pip, no global pip upgrade, 256M PHP memory limit, `TZ` timezone, and `nginx:nginx` ownership syntax.
- Local APK Nginx/Lua packaging changes relative to 2.1.4 are already present in 3.1.6.
- Remove obsolete iconv preload and edge repository overrides; official PHP links GNU iconv.
- Explicitly configure the FPM Unix socket used by Nginx and Supervisor.
- Use the official OPcache loader without loading twice; retain the `OPcache` environment toggle.
- Load Alpine Nginx dynamic modules, including Lua.
- Pin existing PECL versions (Xdebug 3.4.3, Redis 6.2.0, MongoDB 2.0.0) to avoid unrelated upgrades.

The `3.1.6-up1` tag replaces the previously published Alpine 3.23 build. Pull again and recreate containers; existing containers and digest-pinned deployments do not update automatically.

Security release: https://www.php.net/archive/2026.php#2026-10-21-5

```sh
docker build --pull -t cs17899219/nginx-php-fpm:3.1.6-up1 .
sh tests/smoke.sh cs17899219/nginx-php-fpm:3.1.6-up1
# Publish only after testing the downstream image too.
docker push cs17899219/nginx-php-fpm:3.1.6-up1
```

Smoke tests start real containers, exercise Nginx → FPM, check PHP version and common extensions, verify TZ and OPcache enabled/disabled, and repeat after restart. They also check Alpine 3.24, a real Lua HTTP handler, Supervisor process status, and Certbot webroot plugin discovery. Containers are removed afterward; no host ports are published. Downstream also checks its additional extensions during build.

Validated locally on linux/amd64. Business application, external database/Redis integration, actual certificate issuance/renewal, and other architectures require separate validation before production deployment.

The original `/Users/kane/IdeaProjects/nginx-php-fpm` worktree and its custom changes remain intact. The upgrade lives on `security/php-8.2.35` in `/Users/kane/IdeaProjects/nginx-php-fpm-php82-security`.
