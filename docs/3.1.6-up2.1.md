# 3.1.6-up2.1：Nginx 安全回补

从 Git tag `3.1.6-up2`（330b671）独立回补，保留 up2 原有启动、权限、单入口限制和 HTTP 80，不引入 up3 root-init/8080 改造。

## 修复范围

Dockerfile 将 nginx、nginx-mod-http-lua、nginx-mod-devel-kit 同时固定为 Alpine `1.30.7-r0`，避免二进制模块 ABI 不匹配。

依据 https://nginx.org/en/security_advisories.html （2026-11-19 核对），稳定分支 1.30.7 包含此次 HTTP/2 flow-control 内存破坏、HTTP/2/HTTP/3 与 resolver use-after-free、mail proxy 等漏洞修复。具体可利用性取决于模块和配置；升级不表示所有业务或容器提权风险已消除，不把“NGINX2Root”简称等同于单个 CVE。

仅回补 Nginx 的源码配置，不修改 PHP/应用代码。完整构建仍使用旧 Dockerfile 的 apk upgrade 和外部依赖源，可能更新其他系统包；不承诺镜像只有 Nginx 二进制发生变化。

## 构建与发布

Git tag、Docker tag 同为 `3.1.6-up2.1`，不移动/覆盖 `3.1.6-up2` 或 `3.1.6-up3`。从 tag 的干净工作树完整构建，镜像记录 Git revision/version labels。临时安全维护分支仅用于从历史版本回补，不取代 main 开发或 Git tag 发布记录。

```sh
git worktree add --detach ../release-up2.1 3.1.6-up2.1
docker build --label org.opencontainers.image.revision="$(git rev-parse 3.1.6-up2.1^{commit})" \
  --label org.opencontainers.image.version=3.1.6-up2.1 \
  -t cs17899219/nginx-php-fpm:3.1.6-up2.1 ../release-up2.1
```

发布前检查 nginx -v 为1.30.7，校验动态模块版本、nginx配置、PHP-FPM配置，再执行 smoke/single-entry/startup/runtime-settings/shutdown 回归。测试通过才推送 Git tag 和镜像，记录远端 digest。
